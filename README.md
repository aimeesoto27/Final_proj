# Final_proj
Final project for PA 446

I will be investigating 2025 service requests from 311 and answering the questions: Does the method of reported 311 requests impact the time to respond? I have heard some concern regarding ways 311 reports are made. 
Some of my family members think that calling in a 311 service request leads to a faster response time than web and app based requests. I will be addressing this civic concern with my project.
