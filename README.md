# Final_proj
Final project for PA 446

I will be investigating 311 service requests from the past year and answering the questions: Does the area of the service request the time to respond? I have heard some concern regarding where 311 reports come from.
Some residents think that calling in a 311 service request for a more developed area in Chicago, would get faster response time.

I found the dataset from the Chicago Data Portal. The dataset has the method of reporting the request, the initial request time and as well as the completion time and date. 
Furthermore, the dataset includes the service type, the location of the service request and the department the request is assigned. 

After evaluating the data I see that community area #28 has a larger presence in the data with 4942 service requests. On the other hand, community areas such as #47 only have 8 service requests. 
I will keep this in mind as I do my analysis
